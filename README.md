# Laser-Galvo-Projector
High‑speed vector laser projector driven by ESP32 and 15‑25 kpps galvo scanners. Projects vector images, text, animations on walls at ≥15 kpoints/sec. Supports .svg, real‑time UART streaming, offline playback. Safety watchdog + mechanical interlock. Includes firmware (ESP‑IDF) and cross‑platform Python control software.
