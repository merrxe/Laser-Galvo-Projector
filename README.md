# Лазерный проектор векторной графики на базе архитектуры ILDAWaveX16

## Цель проекта
Создать лазерный проектор векторной графики на основе готовых гальванометров (20 Kpps) и микроконтроллера ESP32-S3 по открытой архитектуре **ILDAWaveX16**, способный отображать векторные изображения и анимации на вертикальной поверхности с частотой обновления не менее 20 000 точек в секунду. Устройство должно поддерживать воспроизведение файлов стандартного лазерного формата `.ild`.

## Функционал
- Максимальная скорость рисования: не менее 20 000 точек/сек (20 Kpps).
- Угловое разрешение: не хуже 0.01° (при 16‑битном ЦАП).
- Размер проекционной области на расстоянии 2 м: не менее 1×1 м.
- Мощность лазера: до 100 мВт (класс 3R) с возможностью модернизации до 500 мВт (класс 3B) при обязательном использовании защитных очков.
- Длина волны: 532 нм (зелёный).
- Поддерживаемые форматы: `.ild` (стандарт ILDA), потоковые координаты по сети.
- Режимы работы:
  - *Онлайн* – ПК (скрипт Python) стримит координаты по Wi-Fi/Ethernet.
  - *Автономный* – воспроизведение сцен напрямую с microSD‑карты памяти.

## Задачи проекта
1. Закупка компонентов: гальванометры 20 Kpps с драйверами, микроконтроллер ESP32‑S3, ЦАП DAC80508, лазерный модуль 532 нм с TTL, ОУ LM324, компоненты обвязки питания.
2. 3D‑моделирование в Rhino 8 и печать корпуса с посадочными местами (материал PETG/ABS).
3. Лазерная резка передней и задней панелей из акрила 3 мм.
4. Разработка электрической схемы: связь ESP32‑S3 с DAC80508 по шине SPI, аналоговый каскад на ОУ LM324 для преобразования сигналов ЦАП в дифференциальный сигнал ±5 В для драйверов гальванометров, TTL‑управление лазером, подключение microSD-слота по выделенной шине SPI.
5. Программирование ESP32‑S3 (C++, PlatformIO):
   - Приём пакетов по UDP (сетевые протоколы IDN / IWP) в кольцевой буфер.
   - Синхронная генерация сигналов X/Y через ЦАП по аппаратному таймеру.
   - Управление TTL‑гашением с компенсацией задержки зеркал.
   - Чтение, парсинг и воспроизведение файлов `.ild` с карты памяти для автономной работы.
6. Разработка ПО для ПК (Python):
   - Математическая генерация тестовых паттернов и фигур.
   - Потоковая трансляция кадров на проектор по сети в реальном времени.
7. Сборка, калибровка и тестирование: юстировка, калибровка по сетке с автоматическим расчётом поправочных коэффициентов (линейная коррекция и устранение подушкообразных искажений), определение предельной частоты сканирования.

## Безопасность
- Аппаратный сторожевой таймер (Watchdog) на ESP32‑S3 – принудительно отключает лазер через TTL при прекращении поступления координат или зависании сетевого стека.
- Защита при сбое сканаторов – цепь контроля, блокирующая лазер при падении питания гальванометров или остановке зеркал в одной точке.

## Элементная база
- **Гальванометры**: комплект 20Kpps Galvo Scanner (2 гальванометра с зеркалами, 2 платы драйверов, БП ±15В/24В).
- **Микроконтроллер**: ESP32‑S3 (Dual-Core, поддержка аппаратного SPI и Wi-Fi).
- **ЦАП**: DAC80508 (16 бит, 8 каналов, SPI).
- **Аналоговый тракт**: ОУ LM324 для сдвига уровней и формирования дифференциального сигнала ±5 В. Интегрированный DC-DC повышающий конвертер для аналогового питания ±8 В от USB-C.
- **Лазер**: модуль 532 нм, 100 мВт со встроенным драйвером и TTL‑входом.
- **Хранение данных**: встроенный слот microSD-карт (шина SPI).
- **Конструкция**: пластик PETG/ABS для печати шасси, прозрачный/чёрный акрил 3 мм для панелей.

## Заключение
Разрабатываемый лазерный проектор на базе архитектуры ILDAWaveX16 сочетает высокую разрядность (16 бит), производительность (от 20 000 точек/сек) и современные сетевые интерфейсы. Проект соответствует международным базовым стандартам лазерной индустрии (ILDA), что существенно повышает его научно-практическую ценность.
